Student Research Assistant, Dept. of Information Management, Taipei Veterans General Hospital (VGH)
(Supervisor: Senior Information Engineer Dr. Yuan-Chia Chu)

Middle Ear Disease Diagnosis Research

Contribution

  • Co-Author, AI-Assisted Detection Support for Middle Ear Diseases Using Multimodal Large Language Models (PMID: 40776019).
  • Tested an AI-powered system using Azure OpenAI's GPT-4 Vision, the first multimodal large language model (LLM) applied to analyze otoscopic images from a hospital UI system and detect ten middle ear conditions.
  • Manually filtered low-quality images to ensure clean inputs for model training, transferred low-quality images to physicians to correctly label disease types, and used prompt engineering to define what disease type the model should evaluate.
  • Input otoscopic image data into different Convolutional neural network (CNN) models to identify the middle ear disease type data point with the highest accuracy.
  • Integrated back-end data processing with front-end UI system for otoscopic images using Azure OpenAI API into a Model-View-Controller (MVC)-based application.

Cardiac Signal Analysis Research

Contribution

  • Co-Author, ECG deep learning models optimizing signal pipelines for an arrhythmia detection study presented at MedInfo 2025 International Poster Presentation.
  • Optimizing signal pipelines of patients cardiovascular signals using pre-trained AI models ECG-CLIP and DINOv2 as feature extractor by splitting the patient's cardiovascular signals datasets into 80% training / 20% validation sets.
  • Integrated a Python-based multimodal ECG analysis pipeline by integrating pretrained vision/ECG models, custom signal extraction, feature engineering, cross-validation, and ensemble learning.

Cancer Gene Classification Research

Contribution

  • Co-Author, LLM deep learning models classifying gene variants study presented at MedInfo 2025 International Poster Presentation.
  • Tested the accuracy of GPT-4o, LLaMA 3.1, and Qwen 2.5 in classifying genomic variants of cancer genes over three criteria: accuracy, sensitivity, and specificity.
  • Analyze the performance of each model's ability to label the datasets from OncoKB and CIViC and adjusted the machine learning prompts to select the best-performing model (GPT-4o).

ICU Vital-Sign Monitoring

Contribution

  • Co-Author, Chu Yuan-Chia et al., Prediction of Subsequent Severe Physiological Instability Using the First 6 Hours of Available ICU Vital-Sign Monitoring in an OMOP Common Data Model Database: A Retrospective Model Development and Internal Validation Study, Journal of Medical Internet Research (JMIR); Submitted in August 2026.
  • Defined predictor variables, observation and prediction windows, physiologically plausible ranges, and feature-engineering rules for predicting subsequent physiological instability from ICU vital-sign data using OMOP Common Data Model (OMOP-CDM).
  • Evaluated and interpreted model performance across multiple experimental and validation settings.

Mandarin Tumor-Board Speech

Contribution

  • Co-Author, Getting Who-Said-What Right: A Quality-Gated, Self-Optimizing Algorithm for Faithful Source Attribution in Undiarized Mandarin Tumor-Board Speech, ISCSLP 2026.
  • Assisted in collecting and preparing Mandarin tumor-board meeting audio files at Taipei Veterans General Hospital.
  • Designed and iteratively refined prompts for identifying and attributing clinical opinions to different medical specialties using Gemini-2.5-class.

Smart Ring App UI Design

Contribution

  • Designed prototype of a Smart Ring that can collect data about vital signs through mobile health application interface.
  • Planned the UI workflow for integrating smart-ring sensor data with AI-based health-risk prediction models using Android Studio.

3D Rehabilitation Educational / Home-based Training System

Contribution

  • Created 3D model avatars with Blender, Unity, or Unreal Engine to demonstrate rehabilitation exercises for the Department of Physical Medicine and Rehabilitation.
  • Shadowed rehabilitation patients in hospital and deconstructed movements into distinct steps to plan the animation pipeline, defined and adjusted joint angles, movement sequences, and speed.
