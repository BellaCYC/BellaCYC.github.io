01 / Research Applied

Middle Ear Disease Diagnosis

2023 - Present Student Research Assistant, Dept. of Information Management, Taipei Veterans General Hospital (VGH) (Supervisor: Senior Information Engineer Dr. Yuan-Chia Chu)

GPT-4 Vision (Azure OpenAI) CNN MVC
  • Chu YC, Lin KH, Chou YC, Huang YA, Chen YC, Chen CH, Hsu CY, Cheng YF, Liao WH, Kuo CT. AI-Assisted Detection Support for Middle Ear Diseases Using Multimodal Large Language Models. Stud Health Technol Inform. 2025 Aug 7;329:1059-1063. doi: 10.3233/SHTI251001. PMID: 40776019.
  • Tested an AI-powered system using Azure OpenAI's GPT-4 Vision, the first multimodal large language model (LLM) applied to analyze otoscopic images from a hospital UI system and detect ten middle ear conditions.
  • Manually filtered low-quality images to ensure clean inputs for model training, transferred low-quality images to physicians to correctly label disease types, and used prompt engineering to define what disease type the model should evaluate
  • Input otoscopic image data into different Convolutional neural network (CNN) models to identify the middle ear disease type data point with the highest accuracy
  • Integrated back-end data processing with front-end UI system for otoscopic images using Azure OpenAI API into a Model-View-Controller (MVC)- based application

06 / Discord Bot

EssayBrain

Python Discord.py Gemini AI SQLite
  • Engineered an AI-powered Discord bot in Python using discord.py and Google's Gemini API to act as a Socratic essay coach, guiding users through structured brainstorming without generating raw text.
  • Architected a dynamic Intent Router that contextually parses incoming messages to route requests between Socratic coaching, automated paraphrasing, and historical memory retrieval.
  • Designed a multi-tenant memory engine using SQLite to store and index user achievements, tagging entries with unique Discord IDs to maintain data isolation and privacy across multiple users.
  • Implemented a logical cross-examination feature that queries current user inputs against past database logs to highlight contradictions and expose cognitive biases in essay arguments.
  • Built a long-response handler to tokenize and chunk AI responses exceeding Discord's 2,000-character limit, ensuring seamless multi-message delivery without breaking formatting.
