02 / Discord Bot

EssayBrain

Python Discord.py Gemini AI SQLite
  • Engineered an AI-powered Discord bot in Python using discord.py and Google's Gemini API to act as a Socratic essay coach, guiding users through structured brainstorming without generating raw text.
  • Architected a dynamic Intent Router that contextually parses incoming messages to route requests between Socratic coaching, automated paraphrasing, and historical memory retrieval.
  • Designed a multi-tenant memory engine using SQLite to store and index user achievements, tagging entries with unique Discord IDs to maintain data isolation and privacy across multiple users.
  • Implemented a logical cross-examination feature that queries current user inputs against past database logs to highlight contradictions and expose cognitive biases in essay arguments.
  • Built a long-response handler to tokenize and chunk AI responses exceeding Discord's 2,000-character limit, ensuring seamless multi-message delivery without breaking formatting.
